## 2026-05-03 - Fetch Functions Inside useEffect\n**Learning:** When moving data-fetching functions entirely inside `useEffect` to avoid React dependency linting errors, mutations (like create/update handlers) defined outside the effect will lose access to those fetch functions. This breaks the ability to re-fetch data after a mutation, potentially causing severe UI bugs.\n**Action:** If a data-fetching function needs to be called by both an initial load (`useEffect`) and mutation handlers, define the function outside the `useEffect` (using `useCallback` if necessary, and including it in the dependency array) rather than fully nesting it inside the effect.
