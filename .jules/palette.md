## 2025-05-07 - Contextual ARIA labels and controls for toggle buttons
**Learning:** For interactive UI elements (like accordions or collapsibles) that use generic visual text (such as `[hide]` / `[show]`), it's critical to provide a contextual `aria-label` along with dynamically linked `aria-controls` using React's `useId`. This ensures screen reader users have proper context about what exactly is being toggled and maintains the mapping correctly even if multiple instances exist on a page without ID collisions.
**Action:** When creating or updating accessible interactive widgets (like tabs or collapsibles), prioritize using `useId` for generating unique `aria-controls` mappings and always inject contextual metadata into generic button labels so screen readers provide meaningful context to the users.
