## 2025-05-06 - Contextual ARIA Labels for Generic Text Buttons and aria-controls Mapping
**Learning:** Generic button text like "[hide]" or "[show]" lacks context for screen reader users when multiple collapsible elements exist on a page. Adding contextual `aria-label`s dynamically (e.g., `aria-label="Hide [Title]"`) significantly improves accessibility. Furthermore, generating unique IDs with React's `useId` and mapping them with `aria-controls` explicitly links the toggle button with its content section, while `aria-expanded` accurately reflects state.
**Action:** When implementing collapsible, tabbed, or other toggleable UI widgets, always use `useId` to reliably map `aria-controls` and `aria-expanded` attributes. Also ensure that buttons with short generic visual labels (e.g., icons, "[hide]") are given robust contextual `aria-label`s.
